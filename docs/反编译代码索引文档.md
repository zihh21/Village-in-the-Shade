# 反编译代码索引文档

> 说明：本文档是《Village in the Shade》（日本一/NIS，Steam #3934250）反编译分析的总索引。
> 更新原则：每获取新的反编译信息后必须同步补充本文件；各模块的详细分析单独成文并在此登记链接。

## 1. 项目概述

- **游戏**：Village in the Shade（原生 C++ 引擎 Nmpl/Ngf，内嵌 Lua 5.4 脚本引擎）。
- **主程序**：`village.exe`，PE32+，ImageBase `0x140000000`，编译期默认关闭 ASLR 重定位（基址通常固定）。
- **段映射（rva ↔ 文件偏移）**：
  - `.text`：VA `0x1000` / roff `0x400`，rva − 文件偏移 = `0xC00`
  - `.rdata`：VA `0x9FC000` / roff `0x9FA800`，rva − 文件偏移 = `0x1800`
  - `.data`：VA `0x1004000` / roff `0x1002800`，rva − 文件偏移 = `0x1800`
  - `.pdata`：rva `0x3189000` / foff `0x10D1600`，共计 **31561 个函数**（PE 异常目录）
- **工具链**：见 `docs/` 同目录说明与 `D:\code\.tools\Native\NIS\` 下的 Python 脚本（capstone 反汇编族）。

## 5. 约束与约定

- 不直接修改游戏本体文件；所有 Mod 以**运行时内存 Hook**（inline detour）实现。
- Mod 代码在 `src/<ModName>/`，按语义拆多个 `.cs`（每文件 ≤500 行），版本在 `src/<ModName>/version.txt`。
- 反汇编验证流程：修改 Hook stub 后必须用 `--dump-stub` + capstone 逐指令核对（本项目已如此验证）。
- 函数名优先来源：RTTI lambda 描述符 / ClassID::name；`.data` 中 `0x100xxxx` 的修饰名多为闭包 TypeDescriptor（qword/lea 引用数为 0），不可作为 xref 依据。
- 被替换的 prologue 必须完整复放并跳回（本 Hook 覆盖 15 字节，回跳点在 `target+15`）。
